# 厝內溝通板（Google 版）

給家人、外籍看護和長輩使用的雙語溝通板：點圖卡就會用對方聽得懂的語言說出來，也能即時翻譯對話、播放家人錄的台語。

- **前端**：純 HTML／CSS／JavaScript，放在 GitHub Pages，可加到手機主畫面並離線使用。
- **後端**：Google Apps Script 網頁應用程式，資料存在一份 Google 試算表，台語錄音存在一個雲端硬碟資料夾。
- **登入**：不需要任何個人帳號，只用 6 位數 PIN。

網址：<https://scott-tw.github.io/cuenei-board/>

## 三種角色

| 角色 | 看到的分頁 | 能做的事 |
| --- | --- | --- |
| 家人（含客廳平板） | 阿嬤、家人、對話、錄音、新增圖卡、設定 | 圖卡、對話、錄台語、新增圖卡（要審核） |
| 看護 | 看護、對話、建議修正、設定 | 圖卡、對話、建議修正印尼文 |
| 管理者 | 以上全部，加上「管理」 | 審核、修改與隱藏圖卡、更改 PIN |

客廳平板用**家人 PIN** 登入，裝置命名選「客廳平板」，就會開啟客廳平板模式：預設顯示「阿嬤」分頁、螢幕常亮、每天凌晨 3:00 自動重新整理。這個模式也可以在「設定」裡開關。

## 日常維護

### 更改 PIN、更換看護

**在手機上改（建議）**：用管理者 PIN 登入 →「管理」→「更改 PIN」→ 選角色、輸入新的 6 位數字。

**忘記管理者 PIN 時**：

1. 開啟 Apps Script 專案「厝內溝通板_後端B」→ 左側齒輪「專案設定」→「指令碼屬性」。
2. 新增 `PIN_admin`（或 `PIN_family`、`PIN_carer`），值填新的 6 位數字，儲存。
3. 回編輯器，函式選 `setupPins`，按「執行」。成功後明碼屬性會自動刪除。

更改後，該角色的所有裝置都要用新 PIN 重新登入。看護離職時，改掉看護 PIN，她的手機就無法再使用。三組 PIN 不可相同。

### 新增、修改圖卡

- **家人**：「新增圖卡」分頁。送出後要等管理者在「管理 → 待審核」按「通過」。
- **管理者**：「新增圖卡」直接生效；「管理 → 圖卡管理」可改文字、圖示、播放語言、排序，或把不用的圖卡設為隱藏。
- **直接改試算表**：在 `Cards` 分頁修改即可，各裝置下次開啟時會自動更新。新增一列時 `id` 不可重複，`status` 填 `active`。

時段提示改 `Slots` 分頁，緊急步驟改 `EmergencySteps` 分頁，都不用動程式。

### 看護確認印尼文

請看護用她的 PIN 登入 →「Perbaikan（建議修正）」，逐張按「✓ Benar」或「✏️ Perbaiki」。她送出的建議會出現在管理者的「管理 → 待審核」。

### 台語錄音

家人在「錄音」分頁錄製，先錄「對長輩說」和「緊急」兩組。錄一次，所有裝置下次開啟時會自動下載。每段最長 15 秒。

### 使用紀錄

每次點圖卡、翻譯、緊急的時間與裝置名稱，記在試算表的 `Log` 分頁；不記對話內容。不想記錄時，在指令碼屬性新增 `LOG_ENABLED`，值填 `false`。

### 備份

每月把試算表「厝內溝通板_資料」和資料夾「厝內溝通板_錄音」各複製一份到另一個資料夾。

## 更新程式

### 前端

在專案資料夾執行：

```bash
git add -A
git commit -m "說明這次改了什麼"
git push
```

推送後幾分鐘生效。因為有離線快取，裝置第一次開啟仍是舊版，**再開一次**才是新版。若要強制所有裝置丟掉舊快取，把 `frontend/sw.js` 的 `VERSION` 加 1。

### 後端

```bash
clasp push --force
clasp deploy --deploymentId <目前的部署 ID> --description "說明"
```

部署 ID 就是 `frontend/config.js` 裡網址中 `/s/` 和 `/exec` 之間的那一串。一定要帶 `--deploymentId`，網址才不會變。更新後建議在 Apps Script 編輯器執行一次 `testAll`，最後一行應顯示「全部通過」。

不用 `clasp` 也可以：在編輯器貼上修改後的程式 →「部署 → 管理部署 → 編輯 → 新版本」。

## 從零部署

1. **建立資料**：用要當後端的 Google 帳號建一份空白試算表「厝內溝通板_資料」和一個資料夾「厝內溝通板_錄音」，兩者都不要分享給任何人。
2. **填入代碼**：把試算表與資料夾網址中的代碼填進 `backend/Config.gs`。
3. **推送後端**：在 <https://script.google.com/home/usersettings> 開啟「Google Apps Script API」，然後：

   ```bash
   clasp login
   clasp create --type standalone --title "厝內溝通板_後端" --rootDir backend
   clasp push --force
   clasp deploy --description "初版"
   ```

   `clasp login` 時，同意畫面上的權限要全部勾選。`clasp create` 會覆寫 `backend/appsscript.json`，推送前請確認裡面仍有 `webapp` 設定（執行身分為部署者、存取權為任何人）。
4. **初始化**：在 Apps Script 編輯器執行 `setupAll`（第一次會要求授權），它會寫入設定、建立 7 個分頁與預設內容、安裝試算表編輯觸發器。
5. **設定 PIN**：在指令碼屬性新增 `PIN_admin`、`PIN_family`、`PIN_carer`，執行 `setupPins`。
6. **自我測試**：執行 `testAll`，確認全部通過。
7. **前端**：把部署網址填進 `frontend/config.js`，推送到 GitHub，在儲存庫設定開啟 Pages（`main` 分支、根目錄）。
8. **各裝置**：用 Chrome 開啟網址 → 輸入 PIN → 為裝置命名 → 選單「加到主畫面」。

## 疑難排解

| 狀況 | 處理 |
| --- | --- |
| 沒有印尼語聲音（三星手機） | 手機「設定」搜尋「文字轉語音」，偏好引擎改為 Google 語音服務，並下載印尼語語音資料 |
| 華語聲音是中國口音 | 同上，在語音服務裡安裝「中文（台灣）」 |
| 功能怪怪的 | 「設定 → 裝置檢查」，逐項測試發音、麥克風、連線與翻譯 |
| 更新後看不到新版 | 把頁面關掉重開兩次 |
| 資料沒更新 | 「設定 → 重新下載資料」 |
| 「對長輩說」播的是華語 | 那張卡還沒錄台語，或這台裝置播不了該錄音格式 |
| 顯示「今日翻譯次數已達上限」 | Google 翻譯有每日額度，隔天恢復；圖卡不受影響 |
| 登入或同步突然變得很慢（十幾秒以上） | 曾發生過 Apps Script 專案本身在 Google 端變慢、原因不明的情況。解法是用同一份程式另建一個新專案（照「從零部署」第 3 到 6 步，試算表與資料夾沿用），再把新網址填進 `config.js` |
| 連錯 5 次 PIN | 該裝置鎖定 15 分鐘；全系統 15 分鐘內錯 20 次，所有裝置暫停登入 15 分鐘 |

## 隱私

- 試算表與錄音資料夾只有擁有者能開啟，裝置只能透過後端、憑登入憑證存取。
- 試算表只存 PIN 加鹽後的雜湊值，程式碼中沒有任何 PIN。
- 即時對話的內容不存檔、不上傳紀錄。
- 後端網址是公開的，但所有操作都需要登入憑證。
